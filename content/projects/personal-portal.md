## 它是什么

一个**导航门户**：第一屏就是导航本身。一句主标语压在上面，下面整墙铺开简历 / 博客 /
作品集 / 笔记库这些入口。点卡片不弹小浮层，而是从右侧滑进一整屏详情页。

## 几个自己比较满意的点

- **页面本身永远不滚**。翻屏是把整块面板在原地换掉，文档从头到尾没被滚动过。
- **标题能散成粒子**。点一下，每个字朝外炸开化成粒子，铺满整屏，约两秒后逐字聚回来。
  落点先做分层抽样保证铺满，再叠一层平滑域扭曲，所以疏密是"长出来的"，不像排好队撒的。
- **点击爆点两套**。核心闪光 + 冲击波 + 火星拖尾 / 细环 + 小圆点 + DOM 圆，
  每次点击独立掷一次骰子，网址参数还能把风格钉死，方便做左右对照。
- **零依赖**。没有 npm、没有 CDN、没有外部字体，双击 `index.html` 就能看，离线也能看。

## 性能账

连线是最费的一笔：320 颗粒子两两比距离是 48828 次/帧。按连线半径分格之后只剩 3186 次，
而画出来的线一根不少（1180 条 = 1180 条）。小圆点从"一颗一次 `fill()`"改成按
「颜色 × 透明度档」攒成十几条路径，绘制调用从约 297 次/帧降到 11 次/帧。

> 帧时间没量。无头软渲染环境里的噪声比差别还大，所以"到底还卡不卡"只能在自己机器上感受。

## 技术栈

纯静态：一个 HTML + 一份 CSS + 一份 JS + 一份数据文件。
构建脚本只用 Node 内置模块（拼接、渲染 Markdown、生成页面），服务器上不需要 `node_modules`。
