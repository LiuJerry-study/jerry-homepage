# 个人网站优化实施方案

日期：2026-10-15。范围：网站交互、布局、视觉、性能及工程维护，不涉及个人内容填写。本次交付方案，没有修改业务实现或发布网站。

## 一、目标与边界

保留绿色视觉体系、卡片导航、桌面舞台和标题粒子。推荐最终体验：桌面保留整屏切换，手机与矮窗口采用自然滚动；导航在脚本不可用时仍可用；默认跟随系统主题；标题粒子为主要特色效果，其他反馈从轻。

沿用原生 JS/CSS、零运行依赖、静态快照与动态渲染共用代码的架构。第一轮不更换框架，不重写后台、Markdown 渲染器或粒子引擎。

手机自然滚动是推荐的产品选择，需要与现有布局对比确认，不是已经实测发现故障的结论。

## 二、当前证据

已阅读翻屏、卡片、启动、粒子、主题、性能面板、响应式和构建相关代码。前次运行现有自检通过：24 个页面，以及 7 个后台页面的内联脚本编译。尚未完成浏览器操作、截图视觉审阅及真机性能测试。本文数值为验收目标，不是当前成绩。

直接复用的能力：

- [设置注册](../scripts/lib/features.mjs)：已有主题、转场、爆点、光晕、磁吸、预览开关。
- [粒子系统](../src/js/04-fx.js)：已有 DPR 上限 2、主循环后台暂停、空间分格和批量绘制。
- [性能面板](../src/js/14-perf.js)：已有 FPS、最长帧及消散统计。
- [卡片交互](../src/js/08-cards.js)：已有真实链接、悬停延迟和详情关闭后的焦点恢复。
- [启动逻辑](../src/js/13-boot.js)：已有系统减少动效偏好变化监听，仍需确认每个动画循环真正响应。

优先复现的代码边界：

1. [翻屏控制器](../src/js/09-stage.js)的 popstate 调用 go，paint 对非 instant 更新执行 pushState；历史回放可能再次写入历史。
2. pointercancel 和 pointerup 共用 endDrag，取消事件仍可能满足翻屏阈值。
3. 全局方向键与 PageUp/PageDown 直接翻屏，没有像滚轮一样先考虑面板内部滚动。
4. [首页模板](../src/pages/index.html)的导航容器初始为空，noscript 只有名称列表，脚本不可用时入口不足。
5. 粒子主循环已有暂停，但背景指针 poiLoop 是独立循环，需要完整梳理生命周期。

## 三、工作包 A：导航与输入稳定性（P0）

位置：[翻屏控制器](../src/js/09-stage.js)、[启动和快捷键](../src/js/13-boot.js)、[舞台样式](../src/styles/07-stage.css)。

实施步骤：

1. 给导航增加 push、replace、none 三种历史策略：主动导航 push，初始化 replace，popstate 回放 none。布局测量不写历史。
2. 分离布局计算、活动面板更新、地址更新，避免 paint 或 fitAll 带来导航副作用。
3. pointercancel 只释放捕获、清理状态和还原位移，不提交翻屏；检查 lostpointercapture、窗口失焦时的状态清理。
4. 键盘优先操作可滚内容；焦点在输入、选择、可编辑区或模态面板时不启动舞台快捷键。按钮和链接保留原生激活行为。
5. 滚轮跳过水平手势、缩放和可滚子容器；同一次惯性手势到达内容边界后不立即切屏，下一次独立手势再切换。
6. 以 180–250ms 无滚轮事件作为手势结束的候选范围，使用真实触控板调参；不只依靠翻屏时长防抖。
7. 转场忙碌时最多保留最后一个明确导航请求，取消或布局切换时清理陈旧请求。

验收：后退/前进时面板与地址一致，历史不被重建；取消拖动后不翻屏；键盘能读完长面板；同一触控板手势不会从内容末尾意外跳页；选字、控件操作不触发拖拽。

## 四、工作包 B：默认动效收敛（P1）

位置：[站点配置](../content/site.js)、[功能配置](../content/features.json)、[设置注册](../scripts/lib/features.mjs)、[转场样式](../src/styles/08-transitions.css)。

| 能力 | 推荐默认 | 操作 |
|---|---|---|
| 主题 | 跟随系统 | theme.mode=system，保留访客手动选择 |
| 翻屏 | 固定淡入 | effects.transitionStyle=fade，同步控制器及 CSS 时长 |
| 标题消散 | 保留主动触发 | 保留重入保护，不阻挡导航 |
| 全局点击爆点 | 关闭 | effects.burst=false |
| 光标光晕 | 关闭 | effects.halo=false |
| 按钮磁吸 | 关闭 | effects.magnetic=false，仍保留正常状态反馈 |
| 粒子与柔光 | 低强度保留 | 先减少背景层次，再按性能测量调整 |
| 悬停预览 | 暂保留桌面版本 | 遮挡测试不通过时默认关闭 |
| 随机/实验效果 | 保留可选能力 | 不作为公开默认，无须立即删除代码 |

确认配置合并优先级，通过既有设置体系生效，不建立第二套配置。同步项目兜底值与后台默认值；已保存的显式设置不能默默覆盖。

试调范围：按钮 120–180ms，卡片 160–220ms，翻屏 280–360ms。以实际浏览器对比定稿。减少动效时直接呈现可操作状态，不等待普通转场时长，标题不消失。

验收：首次访问跟随系统、手动选择跨页保持、无主题闪烁、普通点击没有全屏爆点、动画与忙碌锁同步结束、现有开关仍能恢复实验效果。

## 五、工作包 C：手机自然滚动和可读性（P1）

位置：[舞台样式](../src/styles/07-stage.css)、[响应式样式](../src/styles/19-responsive.css)、[基础样式](../src/styles/02-base.css)、[翻屏控制器](../src/js/09-stage.js)。

第一轮候选条件：宽度 <=768 CSS px 或高度 <=600 CSS px 时进入文档流，按实际排版复核断点。减少动效偏好独立控制动画，不直接决定设备布局。

实施：

- 基础 HTML/CSS 默认自然可读；桌面条件满足且初始化成功后再开启舞台锁屏。
- 文档流下取消 stage fixed、panel absolute、非活动面板隐藏及嵌套滚动，内容按正常顺序排列。
- 文档流不消费翻屏滚轮和拖动事件；锚点使用原生导航，保留可见的小节入口，圆点可隐藏。
- 使用统一布局模式状态。跨断点清理拖动、转场、待处理请求，恢复面板可见性、inert 和 aria，再定位当前小节。
- 桌面放不下时优先减空白，不把正文压到不可读；达到排版底线后允许滚动。
- 处理安全区、工具栏、软键盘遮挡。尺寸测量集中执行，避免 resize 中反复读写布局。
- 主要触屏按钮建议 >=44×44 CSS px，正文建议从 16px 起，说明文字按密度和对比度复核。

验收视口：360×640、390×844、768×1024、844×390、1366×768，另测 320 CSS px 宽重排与 200% 放大。无功能性横向滚动、入口遮挡、不可达内容、双重滚动或旋转后空白屏。模拟视口只用于排版检查，触摸手势需真机验证。

## 六、工作包 D：渐进增强和焦点（P1）

位置：[构建入口](../scripts/build.mjs)、[首页模板](../src/pages/index.html)、[卡片交互](../src/js/08-cards.js)、[搜索面板](../src/js/10-palette.js)、[快捷键面板](../src/js/11-keys.js)。

实施：

1. 构建和动态渲染输出真实导航 a 元素，以最终配置和板块开关为唯一数据源。无目标页的项目不得伪造有效链接。
2. 提取共享纯渲染逻辑，浏览器对现有卡片绑定交互，不清空重建节点。新模块纳入拼接清单，保留 file:// 能力。
3. 首轮确保已有可用入口无脚本可访问；无 href 的详情功能提供明确回退，必要时后续补静态详情。
4. 不把 noscript 当唯一兜底：脚本下载失败、执行中断时仍保留基础导航和自然布局。
5. 非活动舞台面板和模态面板后的背景正确设置 inert、aria 与焦点，切换后不把焦点留在隐藏区域。
6. 模态面板内 Tab/Shift+Tab 循环；Escape 关闭后恢复触发点，不存在时回到合理入口。复用已有焦点恢复能力。
7. 保持稳定 h1，装饰字符不重复进入读屏树。可触发标题使用明确按钮语义，支持 Enter/Space。

验收：禁用 JS、阻断主脚本、仅键盘三种情况下均可进入主要页面；焦点不进入隐藏背景；HTTP 与 file:// 均可使用；关闭板块后无残留入口。

## 七、工作包 E：按测量优化性能（P2）

位置：[粒子系统](../src/js/04-fx.js)、[指针交互](../src/js/05-pointer.js)、[标题交互](../src/js/07-title.js)、[性能面板](../src/js/14-perf.js)。

基线：同一设备、浏览器、窗口，分别录制静置、移动指针、标题消散、搜索、连续切屏。每项三次，保留中位结果及异常轨迹。关闭调试面板再测一次，排除统计本身的干扰。

实施顺序：

- 先统一 document.hidden、减少动效、功能开关对应的动画生命周期，停止所有相关 RAF；恢复时重置时间基准。
- 梳理 poiLoop、halo、pointer 独立循环。输入停止且插值收敛、无待播效果时按需停止，新输入再唤醒。动态粒子仍启用时不宣称整页零开销。
- 第一轮只做标准、轻量两档；触屏采用保守预设，减少动效使用静态呈现。不仅凭 UA 或 CPU 核数判定性能。
- 确有瓶颈再降低粒子密度、连线、消散粒子上限或 Canvas 分辨率，优先降低非关键背景。
- 卡片指针每帧最多更新一次，尺寸读取与样式写入分批处理，布局变更后失效尺寸缓存。
- 不先引入 WebGL、Worker 或新框架。

验收目标：代表设备 LCP <=2.5s、CLS <=0.1；交互响应目标 <=200ms，实验室响应与现场 INP 分开报告，无现场数据不宣称 INP 达标。60Hz 代表设备主要动画尽量接近刷新率，帧间隔 P95 初始目标 <=25ms；低端设备不满足时交付轻量档。排查 >50ms 长任务，记录剩余例外。后台和减少动效模式无应用主动持续运行的装饰动画循环。

## 八、工作包 F：视觉统一和维护收尾（P2）

位置：[设计变量](../src/styles/01-design-tokens.css)、[按钮](../src/styles/10-buttons.css)、[卡片](../src/styles/11-cards.css)、[长页面](../src/styles/21-pages.css)。

统一按钮高度、焦点环、边框、阴影和交互时长；卡片最多保留一种主要位移/倾斜反馈。优先检查长页面正文行宽、行高、目录、代码块和返回导航。颜色与装饰以截图对比定稿，不基于源码盲改。

深浅两主题覆盖首页、文章、作品、简历、关于页。普通正文对比度 >=4.5:1，大字 >=3:1，必要控件边界和焦点指示 >=3:1，按实际背景计算。移动端无仅悬停才出现的必要操作。

保留现有后台与渲染架构，只有共享行为需要时提取小模块。浏览器测试工具放在开发验证侧，站点运行依赖继续保持轻量。

## 九、实施顺序和工时

估计为熟悉项目的开发者有效投入，含定向验证，不含等待设备、重新设计和填写内容。

| 批次 | 内容 | 工时 |
|---|---|---|
| 0 | 复现、截图、性能基线 | 2–3 小时 |
| 1 | A 导航输入 + B 默认效果 | 4–7 小时 |
| 2 | C 手机布局 + D 导航与焦点 | 8–12 小时 |
| 3 | E 性能 + F 视觉统一 | 5–9 小时 |
| 4 | 跨主题、跨页、产物回归 | 2–4 小时 |

总计约 21–35 小时，可分 4–6 个工作日。首个可独立发布阶段为基线+A+B，约 6–10 小时，不代表全方案完成。

每批独立提交；静态和动态路径必须共用渲染能力。记录设备、浏览器、基线、改后值及未测项。没有设备或运行环境的项明确标为未测。

实施后在项目根执行 node scripts/build.mjs、node scripts/check.mjs、node scripts/verify-server.mjs；涉及后台设置渲染时再执行 node scripts/admin-check.mjs。首次执行前核对验证脚本的临时文件和进程行为。本次写方案未执行构建或发布。

定向行为回归：历史回放不新增历史、pointercancel 不翻屏、键盘可滚长面板、无脚本入口、板块开关过滤、模态焦点和跨断点状态。无须为颜色微调新增测试。

## 十、回退和完成定义

默认效果用原开关恢复；手机文档流独立回退，避免与动效质量档绑死。有导航或遮挡回归时回退该批次，保留已验证的修复。回退后重新构建并检查静态/动态一致性，避免源码与产物不匹配。

完成标准：桌面保留特色，手机自然阅读；主要入口无脚本可达；输入、历史和焦点可预测；动效有主次；性能有同环境前后数据；构建、后台、file:// 能力不退化；未覆盖设备明确记录。实际发布按后续发布指令执行。
