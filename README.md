# 个人门户 · personal-site

一个**导航门户**：**第一屏就是导航本身** —— 一句主标语「未来 由我们创造」压在上面，
下面整墙铺开简历 / 博客 / 作品集 / 笔记库这些入口。点卡片不弹小浮层，而是
**从右侧滑进一整屏详情页**。

风格：简约 · 高级 · 清新绿。两套主题，一屏一页。

零依赖：没有 npm、没有构建、没有 CDN、没有外部字体，**双击 `index.html` 就能看**。

> **版式定死了：一屏一页（逐屏），而且页面本身锁死不滚。** 翻屏不是把页面滚上去，
> 而是把整块面板在原地换掉；详情页是另开一层、从右侧滑进来的整页。
> `index.html` 是唯一入口。

---

## 一、两块面板 + 一层详情页

| | 是什么 | 怎么进去 | 怎么出来 |
|---|---|---|---|
| **第 1 屏** `#home` | 导航：主标语 + 卡片墙（宽屏 4 列，最后一行不满时居中） | 打开就是 | —— |
| **第 2 屏** `#about` | 关于（占位文案，等你填） | 滚轮 / 空格 / `↓` / 右侧圆点 / `2` | `↑` / 圆点 / `1` |
| **详情页** `#item-page` | 一张卡片的完整详情 | 点卡片（`href` 填过的直接跳走，不进这里） | 「返回导航」/ `Esc` / 向右滑 |

详情页盖住整屏，但**底下的舞台一点没动**：滑回去还是点开前那一屏，连滚动位置都没变。

## 二、它现在怎么动

| 你做什么 | 它怎么回应 |
|---|---|
| 滚轮 / 空格 / `↓` | 翻到下一屏（**页面不动**，内容在原地换） |
| `↑` / `PgUp` | 上一屏 |
| `1` `2` | 直接跳到第 N 屏 |
| 右侧圆点 / 左下角屏序 | 点圆点跳屏；屏序旁边会写着这一屏用了哪套转场 |
| 拖动空白处 | 屏幕跟手挪一点点，松手看距离和速度：够就翻屏，不够就弹回去（有惯性） |
| 点一下大标题 | 整行字**散成粒子、撒满整个屏幕**，约两秒后逐字聚回来；**散着的时候再点它没反应**，只能等它自己聚 |
| 点任意空白 | **爆点**：把周围的粒子轰开，同时炸一下 |
| `Ctrl` / `⌘` + `K` | **命令面板**：搜页面、搜卡片（连 `tags` 一起搜）、执行动作 |
| `?` | 全部快捷键与互动一览 |
| `T` | 明 / 暗主题（从按钮位置圆形揭开） |
| 悬停卡片 | 停 0.42 秒出预览：这条目的前两条详情 |
| 点卡片 | 填过 `href` 的直接跳走；没填的**从右侧滑进整屏详情页** |
| 详情页开着时 | 滚轮、方向键、数字键都不会去翻底下的屏；点击页面空白也不会在背后放看不见的爆点 |

> **「点大标题」和「点空白」是两套效果，互不叠加。** 点标题走的是「字散成粒子」
> （粒子撒进背景层，鼠标推得动、会连线），点空白才是爆点。点标题时刻意不叠爆点 ——
> 两套一起响会互相打架，反而看不清。知道这一点能省掉不少「我点了怎么没反应」。

### 三样东西是随机的

| 随机的 | 开关 | 网址钉死 |
|---|---|---|
| **翻屏转场**：六套（淡入 / 推移 / 翻卡 / 缩放 / 虚化 / 擦除），不连着重复 | `randomTransition` | — |
| **点击爆点**：两套，每次点击**独立**掷一次（连着两下一样是正常的） | `randomBurst` | `?fx=random` / `?fx=new` / `?fx=classic` |
| **主题**：首次打开随机亮 / 暗，**你手动切过一次就记住、不再随机** | `randomTheme` | `?theme=light` / `?theme=dark` |

两套爆点长什么样、想看左右对照，开 **`proto/burst-lab.html`**（那页把两边都钉死了，所以对照是确定的）。

## 三、"页面不滚"是怎么做到的

一句话：**文档（`html` / `body`）被锁死成 `height:100%; overflow:hidden`，翻屏从头到尾没碰过 `window.scrollTo`。**

```
body
├─ div.bg                     固定铺满视口：色洗 + 粒子 + 光斑 + 颗粒（z-index 0）
├─ main.stage                 固定铺满视口，overflow:hidden
│  ├─ section.panel#home      ← 两块面板叠在同一格里
│  └─ section.panel#about        只有一块 .is-active（可见 + 可交互），另一块 visibility:hidden
└─ section.item-page          详情页：默认为 translateX(100%)，加 .is-in 滑到位（z-index 60）
```

翻屏 = 给走的那块加 `.is-out`、来的那块加 `.is-in` + 一个转场类（`.t-fade` … `.t-wipe`），
动画结束把类摘掉。方向（往上一屏还是往下一屏）写在 `.stage[data-dir]` 上，
CSS 里的 `--push / --rot / --ct / --cb` 随方向变，所以六套动效都只写一遍。

**某一屏真的装不下怎么办？** 不是把整个版式关掉，而是三步：

1. **先收紧**：每块面板有一份自己的紧凑系数 `--k`（1 → 0.64，每次减 0.06）。JS 一档一档调，
   直到这一屏的内容排得进一屏 —— 字号、间距、卡片高度都跟着缩。
2. **再屏内滚**：`--k` 到底还排不下（手机上的卡片墙就是这种），就只让**那一屏内部**滚
   （`.panel-scroll`），文档仍然一动不动，左下角屏序旁会挂一个「↕ 屏内可滚」说明。
3. **到边界才翻屏**：屏内滚到底之后，再滚一下才翻到下一屏。

手机（≤640px）单列时必然是第 2 种情况；这时**滑动手势让给屏内滚动**，
翻屏用右侧圆点（触屏上圆点已经放大到 40×22）。

## 四、怎么改内容（90% 的情况只动这一个文件）

打开 **`assets/site-data.js`**：

```js
nav: [
  { title: '个人简历', desc: '教育经历 · 技能栈 · 项目经验', icon: 'resume',
    href: '',                      // ← 做好简历页之后改成 'resume.html'
    badge: '筹备中',
    tags:    ['简历', 'resume', '教育'],        // 命令面板搜得到
    details: ['教育经历：学校 / 专业 / 时间线',  // 悬停预览露两条，详情页看全部
              '技能栈：按熟练度分层列出'] }
]
```

- **`href` 留空** → 卡片显示「筹备中」，点一下**从右侧滑进整屏详情页**，不会跳空白页。
- **`href` 填上** → 卡片自动变成真链接（站内写 `resume.html`，外链写完整 `https://`，
  邮箱写 `mailto:…`，站内锚点写 `#about`），角标自动变「已上线」，点它就直接跳走、不进详情页。
- **加一张卡片** = 往数组里加一个对象。首屏那面墙自己长出来，列数、最后一行居中都不用管。
  图标见 `assets/main.js` 顶部 `ICONS`：
  `resume` `pen` `grid` `book` `user` `mail` `plus` `arrow` `search` `bolt` `page`。
- **详情页不用单独写**：大标题、描述、逐条 `details`、`tags`、底部状态，全是从这条数据渲染的。
- 主标语：`tagline`（首屏那行大字；点它散成粒子，按 `R` 重播浮现）。
- 开关（见下一节）：`showAddCard` / `randomTransition` / `randomBurst` / `randomTheme`。

**加一整屏**：在 `index.html` 里复制一块 `<section class="panel" id="xxx" data-label="小节名">`，
按需要改内容即可 —— 圆点、屏序、命令面板里的「页面」、快捷键 `1/2/…` 全部自动跟上，不用再配一遍。

> HTML 里也写了一份主标语（`data-text` + 标签内的字）—— 那是给**禁用 JavaScript**
> 的浏览器兜底用的。正常改文案只改 `site-data.js`。

## 五、开关与网址参数

**开关都在 `site-data.js`：**

| 开关 | 默认 | 关掉会怎样 |
|---|---|---|
| `showAddCard` | `true` | 不显示最后那张虚线的「＋ 添加新站点」开发卡 |
| `randomTransition` | `true` | 翻屏只用最朴素的淡入 |
| `randomBurst` | `true` | 点击爆点只用新的那套（不再一半概率出现旧的） |
| `randomTheme` | `true` | 首次打开按系统偏好（system dark mode） |

> `randomTheme` 只在**你还没自己选过主题**的时候生效：手动切过一次（按 `T` 或点右上角）
> 就会记住，不再随机。`site-data.js` 因此放在 `<head>` 里加载 —— 主题要在首次绘制前定下来，
> 那个脚本得先读得到这个开关（**改脚本顺序前先想一下这件事**）。

**网址参数（优先于上面所有开关）：**

| 参数 | 作用 |
|---|---|
| `?theme=light` / `?theme=dark` | 强制主题，并且不写入记忆 |
| `?fx=random` / `?fx=new` / `?fx=classic` | 钉死爆点风格，不看 `randomBurst` |
| `#home` / `#about` | 直接开在第 1 / 2 屏（就是两块面板的 id） |

## 七、都有哪些互动

| 互动 | 说明 |
|---|---|
| 六套分屏转场 | 淡入 / 推移 / 翻卡 / 缩放 / 虚化 / 擦除，随机且不连着重复，屏序上会写名字 |
| 卡片详情页 | 点卡片从右侧滑进一整屏（内容按整页排版）；返回按钮 / `Esc` / 向右滑关闭。打开期间翻屏键被屏蔽，底下的舞台原样保留；顶部返回条滚动了才浮出磨砂底 |
| 命令面板 | `Ctrl/⌘+K`：模糊搜索（支持中文子序列）、分组、键盘上下选、回车执行；点卡片那一条也会滑出详情页 |
| 卡片悬停预览 | 停 **420ms** 才浮出前两条详情（免得扫过去一片浮层乱闪），不抢指针（`pointer-events:none`） |
| 磁力按钮 | 指针靠近时按钮「吸」过去一点，松手弹回。**同一时刻只吸最近的那一个**，位移限幅（顶栏 5px / 正文 9px），还会给同级兄弟让路 |
| 拖拽翻屏 | 跟手 + 阻尼 + 惯性判定（距离 76px 或速度 0.5px/ms），到头会拉不动 |
| 标题消散成粒子 | 点一下：每个字朝外炸开、化成粒子，铺满整屏。粒子分两段走 —— 先飞到各自分到的落点（起点是字形，落点是整屏分层抽样后**再叠一层平滑域扭曲**的取样点），落定后就和背景粒子完全一样：鼠标推得动、互相连线；约 2 秒后逐字重聚。散着的时候再点不再提前聚回 |
| 光标光晕 | 跟手缓动，顺着移动方向拉长；悬停可点元素时变大变亮，按下时缩小 |
| 粒子连线 | 近的粒子互相连线，光标附近的粒子连到光标上（像磁铁） |
| 点击爆点 | 每次点击随机二选一：**新**（核心闪光 + 冲击波 + 火星拖尾，整套画在 `#fx-overlay` 上）／**旧**（细环 + 小圆点 + 一个 DOM 圆）。两套都会把周围粒子推开。新爆点自己每次还会换色温（品牌绿 / 偏白 / 偏青 / 偏深）和形状，所以连着点十几下没有两下一样 |
| 对比爆点新旧 | 开 `proto/burst-lab.html`，左旧右新各点几下 |
| 搅动色场 | 两团色斑跟着指针反向漂移，另有一层色洗跟着指针走 |
| 每屏氛围 | 每换一屏，色斑位置、光晕色相、卡片区都跟着变 |
| 逐字浮现 | 每翻回首屏重播一次；按 `R` 手动重播（点标题则是散成粒子） |
| 明暗主题 | 圆形揭开，选择记住；`?theme=light` / `?theme=dark` 可强制 |
| 实时时钟 | 「关于」屏页脚，每秒走 |
| 快捷键 | `1` `2` 跳屏、`Home` / `End` 首末屏、`?` 快捷键表、`Esc` 关浮层 / 详情页 |

## 八、几个刻意的设计选择

### 视觉与手感

- **不加载任何外部字体**：用系统字体栈（Segoe UI / 微软雅黑 / PingFang）。
  代价是各平台字形略有差异，换来的是**首屏零网络请求**、离线可用、不会被墙。
- **绿色只用在几个地方**：光晕、主按钮、标题里「未来」两字、卡片聚光、屏序。
  其余全是低饱和的墨绿灰阶 —— 「清新」靠留白和色相，「高级」靠克制。
- **颗粒质感**：背景叠了一层 3.5% 的噪点（纯 CSS 内联 SVG），防止大面积渐变色带；
  详情页也是同一层颗粒，所以它看起来像「同一个网站的下一页」，而不是一张贴上去的白纸。
- **能点的字不许选中**：整站都是按钮和导航，`user-select: none` 一路禁到底 ——
  桌面上手一滑、手机上长按，就成了「选中文字 → 拽去搜索」，很烦。
  真正要复制的地方只留两处：命令面板的输入框、详情页里的正文。
- **大字只动一下**：首屏那行标题**不拖、不位移**（「按住拖走」那套已经砍掉），
  唯一的互动是「点一下散成粒子」；粒子撒进背景层，散完自己聚回来，首页不会真的缺个标题。
  散着的时候再点它没反应 —— 与其让用户在两秒里来回切换，不如让这一下走完。
- **散开要铺得满，但不能像排好队撒的**：落点先**分层抽样**保证铺满（屏幕切格子、打乱，
  一颗粒子占一格），再叠一层**平滑的域扭曲**（domain warp，低频正弦位移，四个相位每次重掷）。
  只用分层就是一张规则的格子，一眼看出是算出来的；只用纯随机又会这边结块、那边留空。
  域扭曲的好处正在中间：覆盖几乎不变，但格子的规律被打散，压缩的地方自然变密、
  拉伸的地方自然变疏 —— **疏密是长出来的**。再加上每颗粒子自己的起飞延迟、逼近速度、
  侧向漂移（路径因此带弧度而不是直线），就不是「一张被整体平移的图」了。
  粒子数按屏幕面积给（1440×900 约 270 颗），屏幕小就自动少撒。
- **转场宁短不长**：最长 720ms，翻屏锁在转场期间，避免连点滚轮把状态搞乱。

### 详情页为什么是「整屏滑入」，不是「卡片上弹个小面板」

早先的版本是在卡片旁边原地展开一个浮层：要算卡片坐标、要铺遮罩、窄屏还得处理浮层出屏，
而且它把「一屏一页」的节奏打断了 —— 页面不动，却在卡片上面摞了一块。现在改成：

- **一整屏、从右侧滑入**（620ms），内容按整页排版（大标题、56px 图标、逐条正文、标签、底部状态）；
- **返回有三条路**：返回按钮 / `Esc` / 向右滑（跟手拖过 90px 松手）；
- **底下什么都不动**：详情是独立的一层（`#item-page`），舞台、滚动位置、当前第几屏全部原样保留；
- **打开期间屏蔽翻屏**：滚轮、方向键、数字键都不会穿透去动后面的舞台。

### 性能账（每一条都有实测）

| 事项 | 之前 | 现在 |
|---|---|---|
| **连线**：每帧要算多少对粒子（320 颗） | 48828 次距离计算 | **3186 次（15×）**，而且连出来的线**一模一样多**（1180 条 = 1180 条） |
| **小圆点**：散开时每帧的画布 `fill()` 次数 | ~297 次（一颗一次） | **11 次（27×）** |
| **柔和光斑**：每帧新建的渐变对象 | 12 个/帧（≈700 个/秒） | 1 张预渲染的 96×96 贴图，缩放贴上 |
| **指针位置写样式** | 每帧 2 次，不管变没变 | 变了才写，且降到 30Hz |
| **颗粒层混合面积** | 4 倍视口（`inset:-50%`，可图案是 repeat 的，多出来看不见） | 1 倍视口 |
| **点击涟漪** | 每次点击新建一个最大 2600×2600px 的 DOM 层 | 画布上的几个圆、几条线 |
| **连线数组** | 每帧新建 4 个数组、塞一万多个数字 | 复用，不产生垃圾 |

做法本身没什么玄的，就三条：

1. **别做平方级的事**。连线的本质是「谁离谁近」，不分桶就是两两比。粒子按连线半径装进网格后，
   每颗粒子只跟同格 + 邻格比；格子边长取连线半径，所以「可能连上」的一对必定落在 3×3 邻域里，
   一个都不会漏。
2. **绘制调用要合并**。小圆点按「颜色 × 透明度档」攒进十几条路径、一次 `fill` 画完，
   而不是一颗一次。
3. **别每帧做无用功**。值没变就不写样式；不新建渐变对象；不让静态图层白白大四倍。

> **哪些是量出来的、哪些是推理出来的，说清楚**：上面表格里的数字都是量出来的 ——
> 连线那两行是把两套算法喂同样的粒子数跑出来的（跟机器快慢无关，而且连线结果完全一致）；
> 绘制调用数是把 `CanvasRenderingContext2D.prototype` 的 `fill`/`arc` 挂上计数器，
> 在真实页面里数出来的。**没量出来的是「帧时间」**：无头软渲染环境里的噪声比差别还大
> （连把爆炸整个删掉都照样冒毛刺），所以「到底还卡不卡」只能在自己的机器上感受 ——
> 这也正是 `proto/burst-lab.html` 存在的意义。

## 九、兼容与已知边界

| 事项 | 说明 |
|---|---|
| 浏览器 | 现代 Chromium / Safari 15.4+ / Firefox 121+。用到了 `translate` 属性、`clip-path` 转场等；实测 Edge 正常 |
| `file://` 直接打开 | 可以，全部是传统 `<script>`，没用 ES module（module 在 `file://` 下会被 CORS 拦）。`history.pushState` 在 `file://` 下可能被拒，代码里已 try/catch，翻屏不受影响 |
| **改了文件、页面却没变** | 静态资源会被浏览器缓存，先 **`Ctrl+F5` 强制刷新**。想确认自己跑的是哪一版，在网址后面加 `?fx=new`：出现新爆点=新代码，还是旧效果=还是旧代码 |
| 触屏 / 触控笔 | `(pointer: coarse)` 时会关掉 3D 倾斜、旧爆点的 DOM 圆，新爆点的火星也减量（省一点）。爆点本身照常 |
| 窗口偏矮 / 面板装不下 | 先按 `--k` 收紧排版；紧到底才允许那一屏内部滚动，并挂出「↕ 屏内可滚」 |
| 手机 | 首屏单列卡片 + 屏内滚动，翻屏用圆点（或 `1` `2`）；详情页整屏可滚，向右滑返回 |
| 禁用 JavaScript | 退回普通长页面：两屏竖着排、内容都在（`<noscript>` 里那段样式），只是没有转场、详情页和互动 |
| `prefers-reduced-motion` | 全部动效退化为直出（详情页直接出现/消失），导航照常 |
| 本地服务器（可选） | 想更接近线上环境：在本目录跑 `python -m http.server 8000`，然后开 `127.0.0.1:8000` |

## 十、部署

整个目录都是静态文件，**拖到哪都能跑**：

- **GitHub Pages**：把 `personal-site/` 里的文件推到仓库，Settings → Pages → 选分支即可。
  注意页面之间用的是相对路径（`assets/…`），整个目录一起传，别只传 HTML。
- **Vercel / Netlify**：直接拖文件夹，不需要构建命令，输出目录填 `.`。

## 十一、以后要加简历页 / 博客页

**简历页**：复制 `index.html` → 改名 `resume.html` → 把两块 `<section class="panel">` 换成
你要的内容（一块就是一屏），然后把 `site-data.js` 里「个人简历」的 `href` 填成 `'resume.html'`。
样式、主题、转场、快捷键全部自动继承，不用再配一遍。

**博客**：内容会长到几十篇的时候，建议只把 `blog/` 这一块迁去 Astro（Markdown 写作体验最好），
其余页面原样搬过去 —— 这套 HTML/CSS/JS 是纯静态的，任何框架都吃得下。

**想让卡片指向站外**：`href` 直接写完整 `https://…`；
**想指向站内锚点**（比如「关于我」直接跳到第 2 屏）：写 `'#about'` —— 卡片会变成真链接，
点了不会进详情页。
